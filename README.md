# Nexus.xReal
website project template for nexus.co.ps

tech stack:
- html
- css (vanilla, `styles.css` — no build step)
- javascript (vanilla ES modules, `script.js` + `js/`)
- DB none (right now)

no npm, no bundler, no preprocessor. Open `index.html` directly (or serve the folder statically) and edit `styles.css` / `js/*.js` in place.
